# Thesis sweep results

Generated by `make_results.py` from `sweep_summary.csv` and each run's JSON, log and traces. Plan and flags: `instances/thesis_benchmarks/README.md`, "Revised run plan". Machine: one run at a time, 1 s per decision; every run uses `--minGuidePathMs 150`.

## Definitions

Each step has 1 s for the scheduler and planner together (a *decision*). Solver 6 is written s6, at level 6 unless stated. Run-to-run noise is under 0.5% (repeats, below), so differences of 1-2% are real.

- **Deliveries**: tasks finished in the run.
- **Decisions**: decisions made; **bold** when fewer than the steps, i.e. a decision ran over 1 s and every agent waited that step.
- **Backlog clear**: first decision after which at most 1% of agents lack a guide path for the rest of the run (`-` = never). Agents without a path make plain Manhattan moves and can get trapped.
- **Stuck end**: agents that hadn't moved for 20+ decisions, at the last decision.
- **Sched ms**: mean scheduler time per decision.
- **Guide ms / avail**: mean time spent building guide paths per decision, against the mean time available for them (1 s minus scheduler, PIBT reserve of 1 ms per 100 agents, about 80 ms of margins and setup, but at least the 150 ms guarantee).
- **At limit**: share of decisions where guide-path building used up its available time (paths still needed were left for later decisions).
- **Paths/dec**: guide paths built per decision, whole run (last 500 decisions). Agents need one on a new goal (new task, or pickup -> delivery) or when pushed too far off their path. When time is at the limit, this is the number that matters.
- **PIBT ms (max)**: mean (worst) time to choose every agent's move. PIBT isn't time-limited; near or above about 800 ms decisions run late.
- **Long-path ms / cells**: mean build time and length of one guide path whose start and goal are 500+ cells apart (mostly delivery legs). Compare lengths only within one instance.
- **Peak GB**: peak memory of the run (31 GB machine).

Superseded runs (rerun; originals in `superseded/`): `E1_scene_mp_4p_03_80000_s6L6_lift-L4`.

**Reading this table.** The instances keep 1.5 open tasks per agent, so a free agent almost always has a task a few cells away: pickup legs are short and nearly straight (median 1.00 steps per cell; lift's 1.40 at 10k is its detours on short paths), and the distance is in the delivery leg (lead time). *Wait for assignment* mostly reflects the surplus of tasks over agents.
